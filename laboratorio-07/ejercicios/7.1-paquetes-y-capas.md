# Práctica 7.1 — Paquetes, responsabilidades, MVC y arquitectura en capas

## Diagnóstico inicial
1. **Separar menú y cálculo:** se puede cambiar la presentación (consola, web) sin tocar el cálculo, probar el cálculo sin interfaz y entender cada clase por separado.
2. **`package`:** declara a qué paquete (espacio de nombres) pertenece la clase; agrupa por responsabilidad, evita choques de nombres y debe ser coherente con la carpeta del archivo.
3. **Consola vs navegador:** la consola interactúa por terminal y termina cuando acaba `main`; la aplicación web queda como servidor, el navegador envía una petición HTTP y recibe HTML. El navegador no ejecuta el Java del servidor.
4. **Origen de los datos:** lista en memoria, base de datos, archivo o servicio externo. Aquí: lista en `InMemoryPetRepository`.
5. **¿La página decide reglas?** No. El HTML presenta; las reglas en la plantilla no se pueden probar ni reutilizar. Van en el servicio.

## Ejercicio — ¿Dónde ubicarías el cambio?
| Cambio solicitado | Componente |
|---|---|
| Cambiar el texto del título de la página | Vista (plantilla / parámetro `pageTitle` del fragmento) |
| Agregar otra mascota a los datos de ejemplo | Repositorio |
| Obtener una lista de mascotas con una operación reutilizable | Servicio |
| Crear la ruta `/pets` | Controlador |
| Agregar el atributo `species` | Modelo de dominio (`Pet`) |
| Cambiar el estilo de los botones | Recurso estático (`static/css/application.css`) |

## Reto — Explica la separación
```
Navegador --GET /pets--> PetController --> PetService --> InMemoryPetRepository --> List<Pet>
                              |  <---------------- List<Pet> ----------------------|
                              | model.addAttribute("pets", ...)
                              v
                     pets/list.html (Thymeleaf) --> HTML al navegador
```
`Pet` es el dato que viaja entre las cajas.

## Comprobación
- `package` no es una dependencia: ordena tus clases; la dependencia es una biblioteca externa (Thymeleaf) gestionada por Maven.
- El Controller no debe almacenar la información: recibe la petición, pide datos y elige la vista.
- `Pet` (dominio) describe una mascota; `Model` de Spring MVC es el contenedor de atributos que se entrega a la vista.
