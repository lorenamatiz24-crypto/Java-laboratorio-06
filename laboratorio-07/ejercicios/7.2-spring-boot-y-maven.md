# Práctica 7.2 — Spring Boot y Maven

## Laboratorio de errores
> Provoca cada error por separado, anota lo que observes y restaura el proyecto.

1. **Cambiar el puerto** (p. ej. 8081 en `application.yaml`): arranca, pero `http://localhost:8080/` deja de responder y hay que usar `:8081`. Cambió el puerto donde escucha el servidor.
2. **Dependencia mal escrita** (p. ej. `spring-boot-starter-thymelaf`): Maven falla antes de compilar; como el parent no conoce ese artefacto suele indicar que falta la versión (*'dependencies.dependency.version' ... is missing*). El error está en `pom.xml`, no en el Java.
3. **Paquete que no corresponde:** el editor marca que el paquete declarado no coincide con la carpeta (Maven puede incluso compilar). Si la clase principal queda fuera de la raíz de los controladores, Spring no los escanea y `/pets` da 404.

## Comprobación
- **Spring Boot:** arranca y configura la aplicación (servidor embebido, componentes).
- **Maven:** construye el proyecto y gestiona dependencias.
- **`pom.xml`:** parent, Java 21, starters, plugin de Spring Boot.
- **Maven Wrapper (`mvnw`):** ejecuta una versión fija de Maven sin instalarla.
- **`application.yaml`:** configuración leída al iniciar (nombre, puerto 8080).
- **`@SpringBootApplication`:** activa configuración automática y búsqueda de componentes desde su paquete.
- **`main`:** punto de entrada que llama a `SpringApplication.run`.
- **Puerto 8080:** puerta de red donde escucha el servidor.
